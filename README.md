A program that writes one line of weather forecast for a city that does
not exist to `/output/entry.txt`, for the make.fun competition
[Charm the Commuter: Forecast a City That Isn't](https://make.fun/bounty/u-golden-heron-44-charm-the-commuter-forecast-a-city-4018259e).

Run it with Python 3:

```
python3 main.py
```

It writes the forecast below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The forecast is 126 characters, inside the 1 to 140 gate.

## The forecast

```
Today in Brindlewick: sunny spells, a light breeze, and the 8:15 bus arrives on time for once, so mind the miracle, commuters.
```
